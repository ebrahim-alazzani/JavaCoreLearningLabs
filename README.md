# 📚 JavaCoreLearningLabs

A comprehensive educational repository containing hands-on **Java Programming Labs (01-66), Algorithms, Data Structures, and Capstone OOP Course Projects** developed with NetBeans IDE and Maven.

---

## 🗂️ Repository Structure

| Folder / Module | Description |
|---|---|
| `Labs-01-To-66/` | 85 structured lab assignments covering Java basics: loops, conditionals, arrays, methods, exception handling, string manipulation, file I/O, recursion, and object-oriented concepts. |
| `Java-OOP-Final-Capstone-Project/` | Final capstone course project demonstrating advanced Object-Oriented Programming (OOP) concepts: Inheritance, Polymorphism, Abstraction, Encapsulation, and Design Patterns. |
| `Java-Database-CRUD-Project/` | Desktop application connected to relational databases for executing full CRUD operations (Create, Read, Update, Delete) with interactive Swing UI. |

---

## 🎯 Educational Topics Covered
1. **Java Fundamentals:** Variables, data types, control flow, loops, nested conditions.
2. **Object-Oriented Programming (OOP):** Classes, Objects, Constructors, Getters/Setters, Method Overriding/Overloading.
3. **Advanced OOP:** Abstract Classes, Interfaces, Exception handling, Collections Framework (`ArrayList`, `HashMap`).
4. **GUI & Data Persistence:** Swing forms, Event Listeners, File Streams, JDBC connectivity.
